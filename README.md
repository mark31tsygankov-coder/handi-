# HANDI — Macro Helper для Скрайда (Lineage)

Windows-приложение для создания, настройки и запуска макросов клавиатуры и мыши
с профилями, горячими клавишами и системой лицензий.

```
HANDI-project/
├─ app/      приложение (C++20, Qt 6, CMake, SQLite)
│  ├─ src/macro      модель макроса, имена клавиш
│  ├─ src/engine     движок макросов, ввод через SendInput
│  ├─ src/hotkeys    глобальные горячие клавиши Windows
│  ├─ src/profiles   профили, импорт/экспорт JSON
│  ├─ src/settings   SQLite и настройки
│  ├─ src/licensing  клиент лицензий (HTTPS, DPAPI)
│  ├─ src/ui         интерфейс (тема, главная, редактор, активация)
│  ├─ tools          самопроверка ядра
│  └─ build_release.bat   сборка EXE + ZIP
└─ server/   сервер лицензий (PHP 8.1+, MySQL) и админ-панель
```


## 0. Самый простой способ: сборка на GitHub (ничего не устанавливать)
1. Создайте на github.com новый репозиторий (лучше **Private**).
2. Загрузите в него **всё содержимое** этой папки: `app`, `server`, `.github`, `README.md`, `.gitignore` (Add file → Upload files; папку `.github` на телефоне/через сайт удобнее загружать через GitHub Desktop или перетаскиванием на компьютере).
3. Откройте вкладку **Actions** → «Build HANDI». Сборка запускается сама после загрузки (или кнопка **Run workflow**) и занимает 5–10 минут.
4. Готовая программа: вкладка **Releases** справа (файл `HANDI-win64.zip`) или Actions → запуск → Artifacts → `HANDI-win64`.
5. Распакуйте ZIP, запустите `HANDI.exe`, введите ключ из админки.

Адрес сервера лицензий (`https://handi-admin.site.je/api`) уже вписан в `.github/workflows/build.yml`. Если красная галочка: откройте запуск, скопируйте текст ошибки сборки и пришлите разработчику.
Файл `server/config.php` с паролем базы в репозиторий не загружайте (он в `.gitignore`).

## 1. Что умеет программа
- Оверлей-окно без рамки поверх игры (закрепление, прозрачность, перетаскивание), плитки быстрых действий, карточки макросов с выбором клавиши в один клик, поиск, недавние макросы. F10 показывает/скрывает окно.
- Список макросов, создание, редактирование, удаление, запуск, остановка, пауза, продолжение; статус и назначенные клавиши на карточках.
- Редактор: нажатие, удержание, отпускание клавиши, клик ЛКМ/ПКМ/СКМ (в текущей позиции или в точке экрана с захватом позиции), пауза, задержка после каждого действия в мс, порядок, копирование, удаление, повторы, бесконечный повтор, своя клавиша запуска/остановки. Внизу видна визуальная последовательность и длительность прохода.
- Профили: несколько профилей, у каждого свои макросы, быстрое переключение, импорт и экспорт в JSON.
- Глобальные клавиши по умолчанию: F6 запуск, F7 стоп, F8 пауза, F9 продолжить, F10 открыть. Меняются в «Настройки».
- Лицензии: ключ, привязка к ПК, срок, блокировка, защищённое хранение (Windows DPAPI).
- Сворачивание в трей (опция).

## 2. Ограничения и безопасность
Программа использует только обычный ввод Windows (`SendInput`). В ней нет и не будет: инжекта в процесс игры, чтения или записи памяти игры, обхода античита, скрытия процесса, автоматического решения CAPTCHA и проверок «Вы человек?».
Для проверок есть действие **«Ждать подтверждения пользователя»**: макрос встаёт на паузу, окно HANDI выходит на передний план, и продолжить можно только вручную (кнопка или F9).
Совместимость с защитой конкретной игры не проверялась. Использование макросов может нарушать правила игры — ответственность на пользователе.

Нажатия отправляются в окно, которое сейчас в фокусе. При запуске кнопкой в окне HANDI есть задержка 3 секунды, чтобы переключиться в игру. Если игра работает от имени администратора, запускайте HANDI тоже от администратора (иначе Windows не пропустит ввод).

## 3. Требования для сборки
- Windows 10/11 x64
- Visual Studio 2022 (рабочая нагрузка «Разработка классических приложений на C++») или Build Tools
- Qt 6.5 или новее, комплект **MSVC 64-bit**, модули Core, Network, Sql, Widgets (ставятся по умолчанию)
- CMake 3.21+ (идёт вместе с Qt в разделе Tools)

## 4. Сборка через Qt Creator
1. Откройте Qt Creator → «Файл → Открыть файл или проект» → `app/CMakeLists.txt`.
2. Выберите комплект Desktop Qt 6.x MSVC2019/2022 64-bit, включите конфигурацию **Release**.
3. Слева «Проекты → Сборка → Параметры CMake» → найдите `HANDI_LICENSE_API_URL` и впишите `https://ваш-домен/api` (без `/` на конце). Нажмите «Применить параметры CMake».
4. «Сборка → Собрать всё». Цель `handi_selftest` запустите сначала: она проверяет ядро и должна написать «Все проверки пройдены».
5. Запустите цель `handi`.

Если Qt Creator ругается на `HANDI_LICENSE_API_URL`, добавьте параметр вручную: `-DHANDI_LICENSE_API_URL:STRING=https://ваш-домен/api`.

## 5. Сборка EXE и ZIP одним скриптом
1. Откройте **x64 Native Tools Command Prompt for VS 2022**.
2. `cd` в папку `app`.
3. Скопируйте `build_config.example.bat` в `build_config.bat` и впишите `QT_DIR` и адрес API.
4. Запустите `build_release.bat`.

Скрипт настроит проект, соберёт Release, запустит самопроверку, соберёт `dist\HANDI\` с `HANDI.exe` и всеми библиотеками Qt (windeployqt) и создаст `dist\HANDI-1.0.0-win64.zip`. Именно этот ZIP отдавайте пользователям. Шифрование соединения использует системный Schannel, OpenSSL не нужен.

Создание архива вручную: после `windeployqt` выберите папку `dist\HANDI` → правый клик → «Отправить → Сжатая ZIP-папка».

## 6. Публикация сервера лицензий на H1Cloud
Нужны PHP 8.1+ (расширения pdo_mysql, mbstring), MySQL/MariaDB и HTTPS.
1. Создайте базу и пользователя MySQL (в панели хостинга или `CREATE DATABASE handi CHARACTER SET utf8mb4;`).
2. Импортируйте `server/schema.sql` (phpMyAdmin → Импорт, либо `mysql handi < schema.sql`).
3. Скопируйте `config.example.php` в `config.php` и впишите данные базы.
4. Загрузите содержимое папки `server` в корень сайта (например `public_html` или `/var/www/handi`).
5. Включите HTTPS (Let's Encrypt) и редирект с http на https.
6. Откройте `https://ваш-домен/admin/setup.php`, создайте администратора (пароль от 12 символов) и **сразу удалите** `admin/setup.php`.
7. Войдите в `https://ваш-домен/admin/`, создайте тестовый ключ.

**Apache:** `.htaccess` из архива уже закрывает служебные файлы.
**Nginx (VPS):** `.htaccess` не работает, добавьте в `server { ... }`:
```nginx
location ~ ^/(config(\.example)?\.php|schema\.sql|README\.md)$ { deny all; }
location ^~ /includes/ { deny all; }
location = /api/handler.php { deny all; }
location = /admin/layout.php { deny all; }
```
Без этих правил `config.php` может оказаться доступным из интернета, проверьте: `https://ваш-домен/config.php` должен давать 403/404.

**Хостинг не подойдёт**, если он показывает страницу «проверка браузера / включите JavaScript» на запросы API (так делает InfinityFree и его поддомены). Проверка: `Invoke-RestMethod -Method Post https://ваш-домен/api/check.php` должна вернуть JSON с ошибкой, а не HTML.

## 6.1 Как связать приложение и сервер
Единственная связь — адрес `HANDI_LICENSE_API_URL`, который вписывается при сборке. Сменили домен — пересоберите приложение.
Проверка: запустите HANDI → введите тестовый ключ из админки → в админке у ключа появятся устройство и срок.

API: `POST /api/activate.php` и `POST /api/check.php`, JSON `{"key","device_id","device_name"}`, подробнее в `server/README.md`.

## 7. Лицензии на практике
- Срок отсчитывается с момента первой активации. Сроки: 7, 30, 90, 180 дней или навсегда.
- «Сбросить ПК» в админке освобождает ключ для другого компьютера.
- Приложение проверяет лицензию при запуске и каждые 30 минут. Без интернета работает до 72 часов по сохранённой проверке.
- Блокировка и истечение срока останавливают макрос и возвращают окно активации.

## 8. Частые проблемы
| Симптом | Решение |
|---|---|
| «Сервер недоступен» | Проверьте адрес в сборке, HTTPS, откройте `/api/check.php` в браузере |
| «Ключ привязан к другому устройству» | В админке «Сбросить ПК» |
| Макрос запускается, но в игре ничего не происходит | Игра от администратора — запустите HANDI от администратора; убедитесь, что окно игры в фокусе |
| Горячая клавиша не срабатывает | Её занимает другая программа (в Настройках появится предупреждение) — выберите другое сочетание |
| Нет `qsqlite` / ошибка при запуске | Запускайте EXE из папки, собранной `windeployqt` (папка `sqldrivers` рядом с EXE) |
| Ошибка сборки на `windows.h`/`min`/`max` | Используйте MSVC и сборку через предоставленный CMake (определён `NOMINMAX`) |
